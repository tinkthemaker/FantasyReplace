[WIP] PulpDescent

started 2026-03-01 · source

A pulp-text dungeon crawler. You explore rooms, fight, find things, read flavor text. The catch: there is no LLM. Every word you read is hand-authored or generated from a deterministic procedural grammar.

why no LLM

I wanted the game to be:

  • Reproducible. Same seed, same run, forever.
  • Offline. No API key, no rate limit, no outage to explain to a player.
  • Cheap to run. Zero inference cost per play session.
  • Inspectable. I can read every line of generated prose and know why it appeared.

The constraint forced better design. The procedural grammar system ended up being more interesting than any prompt I would have written.

current status

In active development. Combat and discovery systems are in; the remaining work is content, balance, and the things you only find out by playing for fifty hours.
